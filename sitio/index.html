Los tres caminos

/s3

Amazon S3

El ALB redirige al endpoint web del bucket. Solo HTTP.

/ecs/

ECS Fargate

El ALB reenvía a un contenedor nginx en una subred privada.

/vm/

EC2

El ALB reenvía al servidor privado con Amazon Linux y nginx.

El contenedor y el servidor privado descargan estos archivos del bucket al arrancar.
